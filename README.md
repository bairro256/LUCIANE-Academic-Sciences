# LUCIANE Academic Sciences

Portal académico da LUCIANE para Matemática, Física e Química.

## Publicação
O site é publicado automaticamente no GitHub Pages a cada atualização da branch `main`.

## Tecnologias
- React 18 via módulos ES
- Supabase (chave publishable no cliente)
- KaTeX para expressões matemáticas

A segurança dos dados e permissões de acesso é aplicada no backend Supabase através de políticas RLS e funções autorizadas.
